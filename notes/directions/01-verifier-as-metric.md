# 01. 验证器应该是度量，不是打分函数

- 类型: 原创方向判断（非论文笔记）| 日期: 2026-09-15 | 来源: 对 karpathy/autoresearch、Leeroo-AI/kapso、wkqdzkd/Awesome-Reliable-Self-Evolving-Agents 的连续拆解 + 演化生物学/心理物理学的相邻空间检索

## 一句话

**所有自改进系统都把验证器做成了打分函数。标量是错误的形状，正确的形状是度量——空间上的距离结构。** 标量有方向可以刷，必然被 Goodhart；度量没有方向可刷，因为它不是目标，它是坐标系。

---

## 一、证据：三个系统，同一个失败形状

| 系统 | 验证器 | 形状 | 结局 |
|---|---|---|---|
| **autoresearch**（karpathy, 2026-03） | `val_bpb`，held-out 字节上的压缩率 | 标量 | 硬，但固定 5 分钟预算 + 固定 val 分片 → 难度不长，必然见顶 |
| **kapso**（Leeroo, YC X25） | 用户提供的评估器，哈希锁死不可改；卡片需执行过的效果数字才晋级 | 标量 | 工程极严谨（IOAI 2026 超过全部 471 名人类、MLE-Bench 开源第一），但目标由人给，同样见顶 |
| **Awesome-Reliable-Self-Evolving-Agents**（549 篇） | L4 的全部答案 = 让 LLM 自己造 rubric（DR Tulu / EvoRubric / SkillCoach / RubricBench …） | 标量 | 列表自己在 L4 标题下写着特征性失败：**criterion drift** |

这不是三个问题，是同一个问题：**用标量去表示一个本质上需要坐标的东西。**

论证的另一半来自 `notes/papers/15-papergym-rubric-evolution.md`：rubric 是有限维的，优化它必然挤压它没覆盖的维度（新颖性 +16.8 / 严谨性 −9.9）。这正是标量形状的直接后果。

## 二、为什么标量在有人参与的域里必然失败

> **f(作品) 无解。f(作品, 观众) 有解。**

"这张海报好不好"没有确定答案，**不是因为美不可测，而是因为这个问题少写了一个自变量**。非确定性从来不在作品里，它在缺失的观众坐标里。

任何试图从作品单方面算出一个质量数的方案——显著性、处理流畅性、倒 U 唤醒度、压缩进步率、内部自洽性检查——都停留在**理性层**，无法表示**感性层上每个人不同的品味**。它们不是错的物理，是错的形状。

## 三、正确的形状：三个历史先例用的是同一个方法

主观 → 确定性空间，这件事被完整解决过三次，方法相同：**不问好坏，只问等价或比较，从大量这类判断里恢复出空间的维度和度量。**

**① CIE 1931 颜色**（最完整的一次）
颜色曾和审美一样被当作不可言说的主观体验。实验从不问"好不好看"，甚至不问"这是什么颜色"——只让观察者调三个原色直到**看起来一样**。纯匹配判断，二元，无需内省与词汇。从几千次匹配里推出：空间维度是 3（格拉斯曼定律，不是假设而是从数据推出），匹配函数把任何光谱映成三维向量；CIELAB 进一步让距离**感知均匀**，得到 **ΔE**。

**关键：ΔE 从不说哪个颜色更好，它说两个颜色隔多远，单位与人眼一致。距离是确定的，方向是个人的。**

**② Thurstone 比较判断律（1927）/ Bradley-Terry / Elo**
只问"A 还是 B"，从足够多的两两比较里重建一个带度量的区间量表。主观强度可从纯二元比较恢复。

**③ 推荐系统隐空间**（和本问题最同构，工业界已解决二十年）
不问"这部电影好不好"，只收集行为。矩阵分解得到几十到几百维隐空间，**物品和用户在同一空间里都是点**。"好不好"无解；**"对用户 u 好不好" = ⟨p_u, q_i⟩，一个内积，完全确定**。

**④ 语义尺度的原型：Osgood 语义差异法（1957）**
两极形容词定位 + 因子分析，跨几十种语言稳定出三个维度：**评价 / 力量 / 活动（EPA）**，与情绪环形模型（效价—唤醒）对齐。**感性层不是不可测的，它是低维的，五十年代就被测出来过。**

## 四、把"每个人不同"精确化：空间共享，理想点个人

Coombs 展开模型：审美偏好通常**单峰**——每个人在空间里有一个**理想点**，偏好随距离下降（Berlyne 倒 U 推广到多维）。

> **审美空间是共享的。理想点是个人的。好 = 离你的理想点近。**

工程意义：**空间只需被发现一次（贵，全人类共享，可摊销）；之后每个新观众只是定位一个点（便宜）。**

| 阶段 | 代价 | 频率 |
|---|---|---|
| 发现基 + 校准度量 | 贵（大规模比较数据） | **一次性，共享** |
| 定位一个人的理想点 | 约 50–100 次自适应成对比较（d 维需 O(d log n)） | 每人一次 |
| 评估任意新作品 | 一次投影 | **即时、确定** |

这同时回答了"靠选择太慢"：慢的部分被前置并摊销，之后只剩几何。

## 五、突破口：现有规律里没被用的那一块

视觉-语言模型里**已经隐含了这个空间**（从几十亿图文对学出来），但它是纠缠的，且**从未被校准过度量**。两件没人做的事：

1. **提取基**——用稀疏自编码器/字典学习把嵌入空间分解成单义方向（风格、材质、年代、情绪）。这是"逼近一个语义尺度"的现代可行版本。
2. **校准度量**——用人类的**成对比较与匹配判断**（不是评分）把空间重整成感知均匀的，即 CIELAB 对颜色做的那一步。

**交付物不是分数，是距离：视觉设计的 CIELAB。两个设计差多远是确定的，即使哪个更好取决于人。**

一旦有了感知均匀的度量，进化搜索才第一次有了它一直缺的东西：变异步长有单位（一步 = 一个 JND）、MAP-Elites 的网格有正确坐标、新颖性可测（到已有作品集的距离）、风格可做向量运算。

## 六、核心结论：验证器的验证应该做什么

**从"对真值"转向"检验几何自洽"。**

`notes/papers/05-who-grades-the-grader.md` 的核心结论是 **"The anchor cannot be manufactured"**——真值锚点造不出来。但**几何约束可以，因为它来自数学，不来自世界**。

| 检验 | 需要真值吗 | 查什么 |
|---|---|---|
| 三角不等式 d(A,C) ≤ d(A,B)+d(B,C) | **否** | 度量是否自相矛盾 |
| 比较的循环率（A>B>C>A） | **否** | 一致性（Thurstone 的老办法） |
| Procrustes 维度对齐 | **否** | 不同人群重做分解是否恢复出同一个空间 |
| 上下文/顺序不变性 | **否** | 同一对象的坐标稳不稳 |
| JND 预测 vs 实测辨别阈 | 少量 | 尺度对不对 |
| 等距检验（"这两对差得一样多"） | 少量 | 度量是否均匀 |

**前四项完全不需要任何人告诉你什么是好的，却能证伪一个编造的验证器**——被刷过的度量几乎必然违反其中之一。

kapso 已经摸到这个思路：它的 gauntlet 用 duplicate / stability 两个陷阱 **"buy an answer key by construction"**（用构造法买到答案键）。但它只用在记账层（卡片去重、重跑稳定性）。**正确的推广是把构造出来的约束施加到度量本身——那里的约束强得多，因为几何比记账苛刻。**

### 锚点经济学的答案

> **如果验证器是度量，真值需求量从 O(样本数) 掉到 O(维度数)——与样本数无关。**

不需要评判一百万张海报，只需要标定十几个维度的刻度。这是 `notes/papers/_overview.md` 列出的第一个开放瓶颈（"锚点从哪来、要多少、能放大多少倍"）的一个结构性答案，而不是调参结果。

**真值的用途从"评判每个样本"改成"标定一次坐标系"。**

## 七、第一步做什么

1. **改输出形状**：验证器输出坐标 + 距离，不输出分数。同一套东西，换个类型签名，Goodhart 面消失。
2. **建一套无真值的自洽性检验套件**：上表前四项。**领域无关**——对海报成立，对代码、论文评审同样成立。检索 549 篇未见有人做，这是可以单独攻下的一格。
3. **把真值改作标定用途**：像 CIELAB 用 JND 校准尺度那样，只用来钉单位，不用来判断好坏。

## 八、演化学侧的接口（支撑，非主线）

对"越做越好"的机制检索，得到几条与上述正交、可直接施工的结论：

- **内部选择 vs 外部选择**：自然界 99% 以上的筛选由**即时的内部自洽性检查**完成（蛋白质检、细胞凋亡、发育约束、检查点），外部选择只做最后定标。判据不是"好不好"而是"自洽不自洽"——这与第六节的几何自洽检验是同一个思想在不同层的体现。
- **中性网络**：巨大序列空间 → 很小结构空间的多对一，是可进化性的物理基础；**打平的变体必须保留**，中性网是通往新结构的高速公路。autoresearch 式"不进步就 reset"把这条路铲了。
- **相邻可能（Kauffman）**：可行空间随探索自催化扩张，且偏向**能当零件复用**的实现。可操作准则：**选能生出最多可用后代的，而不是当下得分最高的**（可量化：做 N 次变异，统计通过内部选择的比例）。
- **主要演化转变（Maynard Smith & Szathmáry）**：生命史唯一的方向性规律，其内容是**信息组织层级不断加深**（复制子→染色体→真核→多细胞→社会→语言），共同形式是"原本独立的单位绑成更高层单位 + 发明新编码"。对应施工：检测胜出者中的共现模式 → 固化成新组件并命名 → 下一代在更高层空间搜索。**这就是对结构空间自身做压缩**，与压缩进步线合流。
- **中心法则的单向性是安全设计**：蛋白不能反写 DNA。对应——**输出结果不应直接改写模型权重**，中间必须隔一道会过期的门。直接把轨迹喂回训练等于允许蛋白反写 DNA，是模型崩溃与自我强化偏见的机制来源。
- **三层分工（DNA/RNA/蛋白 ↔ 模型/harness/输出）**：保真度由**持久性**决定——RNA 聚合酶错误率比 DNA 聚合酶高约 10⁵ 倍，因为它的错误不持久。今天行业普遍装反：模型层频繁微调，harness 层反而要求严格确定。另：**人和老鼠的蛋白几乎一样，差别主要在调控**——所以该演化的是**调控拓扑**（谁调用谁、什么门控什么、什么在哪衰减），不是 prompt 措辞。措辞属于序列空间，绝大多数改动是中性的，这机制性地解释了 harness 演化收益为何普遍卡在个位数百分点。

## 九、未解决与风险

- **基的可迁移性未验证**：SAE 分解出的方向在不同模型、不同数据分布下是否对齐，没有现成证据。Procrustes 对齐残差本身就是这个问题的检验手段，应当先做这一步再投入。
- **单峰假设可能不成立**：Coombs 理想点模型假设偏好单峰，但强风格偏好可能是多峰的。对策见下。
- **分歧结构是信号，不是噪声**：有了空间与人群坐标后，一张作品得到的是**分布**而非分数。高均值低方差 = 安全平庸；**双峰 = 有争议 = 强风格**；高方差单峰 = 噪声。所有基于打分的系统会把双峰当"评价不稳定"淘汰掉——这可能是它们系统性扼杀强风格的机制。
- **度量本身仍可能漂移**：感知均匀性会随文化与时间变化。对策是把它当表观标记处理——设保质期，定期用新的比较数据重标定，而不是一次固化。
