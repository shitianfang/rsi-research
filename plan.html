把尺子变成被测量的对象

自我改进系统最难的一格是验证：改进循环需要一个裁判，而裁判本身无法被验证，递归下去没有底。本文主张这个困难来自裁判的形状——标量——并给出一个不需要人、难度自己上升的替代构造。

研究计划 · 2026-09-15 · 承接 方向判断、notes/directions/01、experiments/01–03

1. 问题：RSI 里最难的那一格

一个能自我改进的系统需要判断"这次改动是不是更好"。在有确定性裁判的域里（代码跑不跑得过、定理证不证得出），这不是问题。困难出现在裁判本身也会被改进、或者裁判一开始就不存在的时候。

综述把这个困难叫 moving-ruler problem（尺子在动）：

"When both the evaluated system and its criterion change, a rising sequence of internal scores combines two effects: behavioral change under the old standard and movement of the standard itself. Evaluation under only the revised criterion cannot distinguish a more valid rule from one that is merely easier for the revised system to satisfy."

分数在涨，但涨的可能是能力，也可能只是尺子变松了。从分数本身看不出来是哪一种。

2. 我们的论点：这是形状的问题

今天所有自改进系统的裁判都是标量打分函数：s(A) → 一个数。它有一个结构性缺陷，而这个缺陷正好就是 moving-ruler 问题：

标量裁判 s(A) = f( A 的表现 , 尺子的松紧 ) └─────┬─────┘ └─────┬────┘ 想知道的 干扰项 观测到 s 变大了 → 是左边变好了？还是右边变松了？ 一个方程，两个未知数。无解。

而且这不是"测不准"，是结构上不可分辨：无论怎么改进标量的拟合、加多少正则，一个数就是装不下两个自由度。

度量把两个未知数拆成两个可观测量

度量不输出一个数，输出两样东西：

位置 z(A) —— A 在空间里的坐标 局部尺度 M(A) —— 在 A 附近，改动多大才会被察觉（JND 椭球） 尺子变松 → M 整体膨胀（所有方向的 JND 一起变大） ← 可直接观测 能力变好 → z 位置移动，M 不整体变 ← 可直接观测 两个方程，两个未知数。可解。

这就是本文的核心主张：

标量把尺子藏起来了。度量把尺子变成了被测量的对象之一。

于是"验证裁判"这个无底递归被替换掉了：你不需要证明裁判是正确的，你只需要能看见尺子有没有在动。在标量里这不可见，在度量里它是一个显式的量。

3. 方法：七步，全部机器闭合

要把上面那个构造落地，需要一个不依赖人的方式来定义"位置"和"局部尺度"。做法是把评价的顺序倒过来。

普通做法 做出一个东西 ──→ 问 "好不好?" ──→ 没有答案，只能找人 本文的做法 —— 顺序反过来 ① 先写意图 ② 生成 ③ 受限识别 ┌──────────────┐ ┌────────┐ ┌──────────────┐ │ 一个结构 S │ ─────→ │ 产物 A │ ─────→ │ 预算 B 之内 │ ──→ ④ 对比 │（机器写的） │ │ │ │ 把 S 读回来 │ │ └──────────────┘ └────────┘ └──────────────┘ │ │ │ └────────── 真值在这里，是我们自己写的 ─────────────┘
①

写意图

机器生成一个结构 S——不是一个作品，是一个可对比的骨架：阅读顺序、子目标 DAG、程序的分段与秩序。关键在于 S 是先写下的，所以它就是真值，不需要采集、不需要标注。

②

生成

做出一个实现 A 来体现 S。同一个 S 有无数个实现，它们的区别不在对错，而在可恢复性——这正是要研究的量。

③

受限识别

一个资源受限的观察者在预算 B 之内观察 A，输出它读到的结构 Ŝ。观察者不知道 S，它只是在限制下读；它的行为本身就是恢复出的意图。

④

对比

fidelity = dist(S, Ŝ)。纯机械对比，没有任何意见进入。

限制是承重墙，不是装饰。不设预算，任何观察者都能完美恢复任何实现，所有产物同分，信号为零。设了预算，差别才显出来。而"A 在 B 之内能被恢复、B′ 不能"这件事做之前谁也不知道——必须真的生成、真的跑一遍受限识别。这就是它能提供先验之外信息的原因，和"代码不跑不知道崩不崩"是同一回事。
⑤

校准

两件事要定标，而它们是同一条规则：

难度校准：预算调到「完整恢复 / 没恢复」的比例 ≈ 50% 尺子校准：微扰调到「分得出 / 分不出」的比例 ≈ 50% 原因：二元判断在 50% 处熵最大，每次测量拿到的信息最多。 90% 通过率的那次测试几乎什么都没告诉你——你本来就猜得到它会过。

尺子校准给出单位：从 A 出发沿方向 δ 推 t，找到刚好一半能被分辨的 t*，那就是该方向上的 1 个单位。所有方向的 t* 连起来是一个椭球，它就是 M(A)。

↑ 0.30 推 0.30 才分得出 → 这个方向迟钝 │ ←─────────●─────────→ 推 0.05 就分得出 → 这个方向敏感 0.05 A 0.05 │ ↓ 0.30 连起来 = ╭─────╮ │ A │ ← M(A) ╰─────╯

难度校准只看当前这批产物的通过率，不看任何外部标准。所以产物变好时预算自动收紧——校准规则本身就是难度上升规则，两者是同一件事，不是另外加的机制。

⑥

学习

循环累积的不是分数，是三样东西：

  1. 敏感度地图——哪些方向承载意义（动一点就改变被读出的结构），哪些方向是自由的（动很多也读不出差别）。这把产物空间切成"必须锁死的轴"和"随便发挥的轴"。
  2. 结构规律——形如"当某结构特征满足某条件时，崩溃阈值平均高 N 档"。是可解释的句子，不是分数。
  3. 意图→实现的映射——给定 S，哪些实现方式能在紧预算下把 S 传达出去。这是能力，前两样是知识。
⑦

自进化

预算变紧 → 尺子变细 → 分出以前分不出的差别 → 学到更细的规律 ↑ │ └──────── 产物变好，通过率回升，于是预算再紧一档 ←────┘

复利来自一个具体的事实：度量的分辨率是算力的函数，而算力是系统可以多花的东西。"改进者改进自己"在这里有了所指——不是让裁判更聪明，是让它看得更细。

4. 为什么这解决了验证问题

验证的老问题这个构造里发生了什么
裁判从哪来不需要裁判判"好"。真值是先写下的意图，对比是机械的
谁验证裁判不验证它正不正确，观测尺子有没有在动（M 是否整体膨胀）。这在标量里不可见
信息从哪来"在预算内能否恢复"是执行的经验事实，不跑不知道——超出生成器的先验
难度会不会见顶校准规则即escalation规则，产物变好预算自动收紧
要多少人零。测试机器生成，预算是一个数字，意图是机器写的

5. 通用性

七步里没有一步依赖具体域。唯一的前提是：能先写下意图，且产物空间能被微扰。

域① 意图 S② 产物③ 预算④ 恢复 Ŝ
程序分段与秩序结构实现调用次数从输入输出归纳出的分段
agent子目标 DAG调控拓扑步数、上下文轨迹里实际的子目标顺序
策略目标状态序列policy交互次数rollout 实际到达的序列
数据管线字段依赖图ETL 代码采样行数从样本推断出的依赖
视觉设计阅读顺序版面注视次数、分辨率注视序列落在哪些元素上

于是通用的距离只有一个式子：

d(A, B) = 在预算 B 之内，能把 A 和 B 区分开的概率。

程序里是"8 次调用之内有没有一个探测让两者表现不同"，agent 里是"K 步之内有没有一个任务让两套拓扑走出不同轨迹"。同一个式子。

限制逼出的是真品质，不是人造考试

程序域里有个干净的例子：两个实现都正确，都是三段函数、断点都在 0 和 10。但 A 在 x=10 处只跳变 0.001，B 跳变明显。8 次调用之内，A 只能被恢复出 1 个断点，B 能恢复出 2 个。

它们在无限预算下完全等价；是预算把它们分开的。而分开的那个东西正是可发现性 / 可测试性——一个真实的工程品质。这说明限制不是硬凑的考试，限制逼出的正是"在有限资源下还能不能被正确理解"，而这在任何域里都是真品质。

幸存的（均为预先指定的次要观测，不构成主线）：

  • 固定预算下度量显著优于标量：Δ阶梯真值 +0.059（2se 0.040，配对 8 种子）。「优化体积比优化点迁移得好」这半句活着；「预算上升是引擎」那半句死了。
  • 度量确实各向异性（E-A）：同一实现不同方向的 JND 半径差 54.7×（预算 6）/ 22.3×（预算 12）。几何是真实的——若各向同性，度量将退化为标量。
  • 阶梯自己找到 50% 点（E-B，从 20 收敛到 12 附近震荡）。机制活着，只是不带来收益。
  • far-from-training 列跨臂不可比（各臂终点预算不同，"2 倍远"的档位集合随之不同），不据它下任何结论。

8. 局限

  • 它测的是传达/恢复的鲁棒性，不是美，也不是个人品味。在视觉设计上，它能让及格线自动上升并精确交还创作自由度（告诉你哪些轴是自由的），但它判断不了美。
  • 人的位置：空间由机器免费建成，人只需在已建好的空间里指一个点，成本 O(维度) 而非 O(样本)。机器建地图，人选目的地。
  • 首个实验域刻意选程序而非设计——那里有独立可计算的真值来核对度量有没有自欺。在没有独立核对手段的域先做，等于自证。
  • 四臂对照已于 2026-09-15 完成（NameError 已修，E-A/E-B/E-C 全部跑通；为"平台化"判据补了 t=20/40 两个中途阶梯测量点，判据本身未动）。结果与裁定见第 6 节：预注册失败分支触发。

E-D3：漏答案的裁判（新一轮，主人已授权；玩具域的终局轮）

E-D2 的终止条款封的是轮内迭代；主人指令继续后开启本轮。与前两轮的区别不是调参，是修一个构造缺陷：mode-guessing hack 的分数天花板（≈+0.13～0.17）会被个别种子的真进步超出，两轮 MC 都因此失效。E-D3 的 hack 换成漏答案的裁判：以概率 q 不读产物、直接吐出该产物的真值意图。这对应现实里最危险的裁判失效——记住了答案集、或与生成器串通：分数漂亮，测量已停止。它的分数天花板是保真度上界本身（q=1 时保真=1），而任何真进步的涨幅按定义不超过 1−s₀，所以上一轮的失效方式在结构上不可能再发生——这就是为什么它是修缺陷而不是钓显著。

  • 条件结构与读数定义不变（冻结参照件、log JND 均值、逐种子对抗校准——q 二分匹配该种子的真进步涨幅）；能力注入恢复 rounds=25（天花板已不设限）；粗尺阈值起点 8.0；方向数 8、判别重复 8；12 个全新种子（400–411），预检种子照旧只做门控。

修订（预检之后、注册块接触之前；调难度，判据与终止条款不动）：把恢复任务从「读句序」改成读篇幅——要点增至 5 个，段落的出现顺序被刻意打乱，真正的优先级只通过每个要点获得的详述篇幅与强调传达，且禁用一切排序词。于是恢复必须做推断而非抄读。真进步臂（improved）改为显式排序重写（"Most importantly / Second / …"，按优先序一句一点），这是一次真实的表达质量提升，其增益由 PC3 独立核验。l2 扰动相应变为「交换最高与次高优先级，出现顺序不变」——比换句序更细的信号，电池因此也有了余量。语料按此重新生成（注册块 2–9 从未被测量，重生成不构成偷看）。

「为什么不直接用现成 benchmark」（主人之问，已专项核查）：现成裁判基准测的是「裁判有多准」（带标注题对 → 准确率），而 E-R 测的是漂移监测器——注入病变、逐块校准、真进步对照臂、免标注真值，这四样没有任何公开基准自带，harness 本身就是实验；基准能捐的只有语料，而语料是全实验最便宜的部分（240 次 haiku 调用）。核查结论（子代理调查，2026-09-15）：Dark Current 未公开数据（电池规格可复刻、原始刺激不可复跑，跨文数字不可比）；JudgeBench（MIT，350+270 个客观正误对，冻结、免再生成）是外部效度复现轮的首选语料——在别人写的题对上跑我们的监测器；届时梯度扰动阶梯（唯一先例是 BabelJudge 的两档退化生成器）、同对底噪试验（唯一近邻是 RAND harness 的重复采样，未捆绑语料）、病变注入与真进步臂仍全部由我们的 harness 提供。该复现属 E-R 之后的独立一轮。
